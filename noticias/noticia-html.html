Microsoft cria IA que trabalha sozinha enquanto você está longe do PC; conheça

Microsoft anuncia novidades no Copilot, incluindo recursos para criar soluções por comando e um agente que pode executar tarefas sozinho; veja como funcionam as novidades

A Microsoft anunciou, nesta sexta-feira (25), novos recursos para o Copilot, e o TechTudo acompanhou as reformulações da plataforma de inteligência artificial. Entre as novidades estão as novas funcionalidades para conversar com a IA, delegar tarefas, criar aplicativos e automatizar as atividades. Segundo a desenvolvedora, as novidades chegam para conectar as ferramentas que as pessoas já usam a novos recursos do Copilot, ajudando a desenvolver, personalizar e ampliar o uso no trabalho. O principal destaque é o Autopilot, que funciona como uma espécie de funcionário virtual dentro do Copilot, capaz de continuar trabalhando de forma autônoma mesmo quando o usuário não está usando o computador. A seguir, confira as principais novidades anunciadas pela Microsoft.

O que mudou no novo Copilot?

De acordo com a Microsoft, o novo Copilot ou os novos recursos integrados à ferramenta de inteligência artificial, vão ajudar a personalizar e ampliar o uso no trabalho. Com isso, a fabricante de software anunciou novas funcionalidades, entre elas estão o Home, o Code e o Autopilot. O Home será a nova tela inicial do Copilot e vai reunir o Chat e Cowork num só lugar. Nele será possível revisar as atividades recentes, receber sugestões sobre como a IA pode te ajudar, além de voltar ao trabalho de onde parou. A Microsoft também vai integrar ferramentas do Word, Excel e PowerPoint diretamente à experiência, permitindo criar e editar conteúdos sem precisar sair do Copilot. Já o Code foi pensado para ajudar os usuários a criar as próprias soluções com IA. A ferramenta usa a mesma tecnologia do GitHub Copilot e conta com recursos para executar os códigos com segurança. O Autopilot funciona como um funcionário virtual. Ele pode receber uma tarefa e continuar trabalhando de forma autônoma, mesmo quando o usuário não está usando o computador. O agente pode acompanhar projetos, executar tarefas e retomar trabalhos sem precisar receber um novo comando a cada etapa. Segundo a Microsoft, o Home e o Code começarão a chegar nas próximas semanas para participantes do programa Frontier. O Autopilot, por sua vez, será disponibilizado para um grupo de usuários em uma prévia privada no fim do mês.

Autopilot: a IA que trabalha sozinha

Entre os destaques está o Autopilot, que vai funcionar como uma espécie de colega de trabalho virtual dentro do Copilot. Segundo a Microsoft, ele poderá trabalhar pelo usuário. Para isso, é preciso dar um nome e uma função ao agente, que então poderá começar a trabalhar, monitorando canais e executando tarefas recorrentes. Também será possível retomar projetos dias depois, sem a necessidade de enviar um novo prompt. O Autopilot também fica integrado às ferramentas que as empresas já utilizam, como Teams, Outlook, chats, canais e documentos. Dessa forma, a proposta é que ele funcione como um funcionário digital, com acesso controlado aos dados e às ferramentas necessárias para realizar suas tarefas, enquanto o usuário acompanha o trabalho e define os limites do que o agente pode fazer.

Copilot agora cria aplicativos por comando

O Code foi desenvolvido com a mesma tecnologia do GitHub Copilot, sendo executado num ambiente isolado e hospedado com segurança dentro do tenant. Em outras palavras, essa novidade é voltada para programação, processado num espaço separado e controlado, além de seguir regras de segurança. Este novo recurso também permite criar pequenas soluções usando apenas comandos de texto. Na prática, o usuário pode explicar ao Copilot o que deseja criar, como um aplicativo, um painel ou uma ferramenta para automatizar uma tarefa. A partir dessas instruções, a IA escolhe a melhor forma de desenvolver a solução e cria o projeto. A proposta é facilitar a criação de ferramentas mesmo para quem não tem conhecimento avançado em programação.

Word, Excel e PowerPoint ficam dentro do Copilot

Agora, os programas do Microsoft 365, como Word, Excel e PowerPoint foram levados para o Office no Copilot. Com essa novidade, o usuário pode criar e editar documentos, planilhas e fazer apresentações a partir de comandos em linguagem natural, sem precisar alternar entre diferentes aplicativos. Com isso, a nova funcionalidade manterá os arquivos sincronizados entre o Copilot e os aplicativos do Office. Assim, as equipes poderão trabalhar simultaneamente nos mesmos documentos e acompanhar as alterações em tempo real. Por exemplo, no PowerPoint, a IA vai ajudar a aplicar modelos e manter a identidade visual nas apresentações. Já no Excel, vai ser possível identificar alterações feitas nos arquivos e será recomendado gráficos que facilitem a visualização dos gráficos.

Quando as novidades estarão disponíveis?

Segundo a Microsoft, os novos recursos serão disponibilizados em períodos diferentes. O Home começa ser disponibilizado ainda no mês de setembro. Já o Code chega ao programa Frontier no final do mesmo mês e terá mais disponibilidade nas semanas seguintes. Porém, para assinantes do Microsoft 365 Premium e Pro, a prévia está prevista ainda em 2026. O Autopliot será expandido para prévia privada no fim de setembro. Ou seja, a partir desse período, mais usuários selecionados poderão testar o recurso antes do lançamento oficial.
